The Skill Library · new paradigm

You have a problem.
Here is the machine that solves it.

Scroll and the camera flies through the workflow on the left: problem → ways to solve it → a Solution Skill → the product. Each Solution Skill is a chain of the skills this library already contains — ordered, with the hand-off between them named, and every skill credited to its own author.

01 · problem

Problems, not categories.

People arrive with a job to do, not a taxonomy to browse. The front of the library is a list of concrete problems. Here are the first three, each with a composed solution drawn from the real skill tree.

02 · ways to solve it

Every problem has routes. Each route has a trade-off.

Disciplined vs. prototype-first vs. smallest honest thing. The reader sees the cost before choosing — one prescriptive answer would be a lie.
