The upstream `engineering/grill-me`, `engineering/grill-with-docs`, `engineering/handoff`, and `productivity/handoff` were not imported because this repository already contains equivalent local skills. The local `skills/engineering/grill-with-docs/`, `skills/productivity/grill-me/`, and `skills/productivity/handoff/` guides remain authoritative.
