# UI/UX Pro Max

Use this skill to guide UI implementation or review with UI styles, color palettes, typography, accessibility checks, charts, and stack-specific recommendations.

## Quick start

From the repository root:

```bash
python3 skills/design/ui-ux-pro-max/scripts/search.py "fintech banking dashboard" --design-system -p "Finance Console"
```

Use `--domain` for focused guidance, or `--stack` for framework-specific recommendations. See [SKILL.md](SKILL.md) for the full workflow and available options.
