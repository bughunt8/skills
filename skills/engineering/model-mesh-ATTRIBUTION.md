# model-mesh attribution

The `mm-method`, `mm-loop`, `mm-verify`, and `mm-domain` directories were imported
from [bughunt8/model-mesh](https://github.com/bughunt8/model-mesh) at commit
[`fec459103a00a4d5e052a86fc87a2521e0482bba`](https://github.com/bughunt8/model-mesh/tree/fec459103a00a4d5e052a86fc87a2521e0482bba).
They are distributed under the MIT License reproduced in
[model-mesh-LICENSE](model-mesh-LICENSE).

## Upstream notices

### fable-method (MIT)

The imported loop skills are adapted from and integrated with
[fable-method](https://github.com/Sahir619/fable-method) by Sahir619. Upstream
skills were renamed to the `mm-*` names, real model and provider names were
replaced with behavioral descriptions, and the documentation was rewritten for
model-mesh. The upstream MIT copyright is retained in
[model-mesh-LICENSE](model-mesh-LICENSE).

### matt-pocock/skills (concepts adapted)

The `mm-method` loop adapts ideas from
[matt-pocock/skills](https://github.com/mattpocock/skills) by Matt Pocock:
requirement-sharpening interviews, throwaway prototypes, test-first vertical
slices, and two-axis code review. These are conceptual adaptations rewritten
for model-mesh; no files were copied verbatim.

### debug-pipeline2 (concepts adapted)

The evidence discipline is adapted from the debug-pipeline2 audit-fix-prove
protocol by ronald-ng (MIT), including machine-checkable evidence, negative
tests, false-green defence, and independent-reviewer isolation. These are
conceptual adaptations rewritten for generic coding; its pipeline-specific
machinery was not included.

### oh-my-openagent

The imported skills may refer to the
[oh-my-openagent / opencode framework](https://github.com/code-yeongyu/oh-my-openagent).
Those framework names are retained in the upstream documentation as real
identifiers, not model or provider names.
